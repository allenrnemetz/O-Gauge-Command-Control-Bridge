==============================================================
  LIONEL MTH COMMAND CONTROL BRIDGE - EASY INSTALL
==============================================================

  This file has simple instructions for installing the bridge
  software without needing to know Linux.

  You should be sitting in front of the computer or Raspberry Pi
  that will run the bridge, with its desktop screen visible.


------------------------------------------------------------
  WHAT YOU NEED BEFORE STARTING
------------------------------------------------------------

  1. Your FTDI USB-serial adapter plugged into a USB port
     on this computer/Pi

  2. Your MTH WTIU powered on and connected to your network
     (same WiFi or same router as this computer/Pi)

  3. Your Lionel Base 3 and remote ready (you don't need
     these for the install, just for using the bridge later)


------------------------------------------------------------
  STEP 1: DOWNLOAD THE SOFTWARE
------------------------------------------------------------

  Open your web browser and go to:

     https://github.com/allenrnemetz/O-Gauge-Command-Control-Bridge-on-Pi/releases/latest

  Scroll down to the "Assets" section and click:

     Source code (zip)

  This downloads a ZIP file to your Downloads folder.


------------------------------------------------------------
  STEP 2: EXTRACT THE ZIP
------------------------------------------------------------

  Find the downloaded ZIP file (usually in your Downloads
  folder). It will be named something like:

     O-Gauge-Command-Control-Bridge-on-Pi-1.3.0.zip

  Right-click it and choose:

     "Extract Here"  (or "Extract to folder...")

  You should now see a folder with the extracted files.


------------------------------------------------------------
  STEP 3: MAKE THE INSTALLER CLICKABLE (ONE-TIME)
------------------------------------------------------------

  Open the extracted folder. Right-click anywhere in the
  folder and choose:

     "Open Terminal Here"  (or "Open in Terminal")

  In the terminal window, type:

     bash setup.sh

  and press Enter. This makes the installer and updater
  icons clickable. You only need to do this once.

  (You can close the terminal after it says "Done!")


------------------------------------------------------------
  STEP 4: RUN THE INSTALLER
------------------------------------------------------------

  In the same folder, double-click:

     Install Bridge

  A window will pop up guiding you through the installation.
  Just click OK / answer the questions and click OK.

  When it asks for your password, type the password you use
  to log into this computer/Pi. (This is needed to install
  the background service.)


------------------------------------------------------------
  IF DOUBLE-CLICK STILL DOESN'T WORK
------------------------------------------------------------

  Some systems may still need permission. Try:

  Option A: Right-click "Install Bridge" and look for:
     - "Allow launching" or
     - "Properties" -> "Permissions" -> check "Allow executing
       file as program"
     Then double-click it again.

  Option B: Open a terminal in this folder and type:

     bash gui_install.sh

     then press Enter.


------------------------------------------------------------
  STEP 5: CHECK IT'S WORKING
------------------------------------------------------------

  After the installer finishes, it will tell you it's done.

  To verify the bridge is running, open a terminal and type:

     sudo systemctl status lionel-mth-bridge

  You should see "active (running)" in green.

  To see live logs of what the bridge is doing:

     sudo journalctl -u lionel-mth-bridge -f

  Press Ctrl+C to stop viewing logs (the bridge keeps running).


------------------------------------------------------------
  STEP 6: ADD YOUR ENGINES (ONE-TIME SETUP)
------------------------------------------------------------

  Before you can control trains, you need to add your MTH
  engines to the WTIU using the MTH DCS app on your phone
  or tablet:

     1. Open the MTH DCS app
     2. Connect to your WTIU
     3. Go to "Add Engine" and follow the prompts
     4. Note the engine number shown in the app

  Then set your Lionel remote to the same engine number.
  The bridge handles the rest automatically.


------------------------------------------------------------
  UPDATING THE BRIDGE LATER
------------------------------------------------------------

  When a new version comes out, updating is easy:

  1. Find the folder where you originally installed the
     bridge (the one with "Install Bridge" and "Update
     Bridge" in it).

  2. Double-click "Update Bridge".

  3. That's it! The updater will:
     • Download the latest version from GitHub
     • Replace the bridge files (your settings are kept)
     • Restart the bridge

  You don't need to download anything yourself — the
  updater fetches the latest release automatically.

  You may be asked for your password during the update.
  This is normal (it's needed to restart the service).
